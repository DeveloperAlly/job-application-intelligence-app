# Career OS

An open-source, self-hostable career application system built around verified evidence and human approval at consequential decisions. Implementation is partial; the product and hosted PM system are not yet accepted.

Start with [current state](STATE.md), [product contract](what/context/product-contract.md), [requirements](pm/03-requirements.md), [architecture](pm/05-architecture.md), and [PM operating contract](PROJECT_MANAGER.md). The [publication reconciliation](how/publication-reconciliation-2026-09-10.md) explains the current authority and validation boundaries.

Run all nested Python test files from the repository root with `python3 tools/run_tests.py`. The old top-level unittest discovery command found zero tests and is not a valid success check. Test dependencies include Pillow and pypdf; local evidence-store checks may require ignored private data and must report that limitation.
