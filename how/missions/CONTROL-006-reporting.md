# CONTROL-006 — Coordinator reporting contract

## State
READY after persistent coordinator acceptance.

## Outcome
Ensure the human receives concise proactive reports without polling the project.

## Report format
Every report contains exactly these sections when applicable:
- COMPLETED
- RUNNING
- BLOCKED
- DECISION REQUIRED
- NEXT STEPS
- COMPLETE CHECKLIST

## Rules
- No process narration.
- No speculative status.
- Every completed claim must be backed by repository/GitHub/test evidence.
- Every blocked item must name the exact unblock action and owner.
- Every response must include the full current checklist and explicit next steps.
