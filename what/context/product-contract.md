# Career OS — Agreed Product Contract

Status: ACTIVE

## Product
An open-source, self-hostable career automation operating system with human approval at consequential decisions.

## Proposition
**Your career evidence, compiled for every job.**

The durable asset is verified career evidence. Resumes, cover letters and related application documents are derived outputs.

## Lifecycle
Find jobs automatically → score → generate tailored application kits → user approves → send → track → follow up → infer status from email → learn from outcomes.

## Product shape
Career OS is not primarily a resume editor. The core wedge is:

job → evidence → tailored application compiler

## Core principles
- Evidence before generation.
- No invented claims or metrics.
- Explainable reasoning over durable facts.
- Human approval for consequential external actions.
- Deterministic orchestration for state, scheduling, dedupe and hard constraints.
- Bounded agents only; no unconstrained agent loops.
- Open-source/self-hostable BYOK/BYO infrastructure.
- Database = facts and durable derived knowledge.
- Intelligence = explainable decisions over facts.
- Application layer = actions and workflows.
